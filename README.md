# Numora

**Bilder per Tastatur oder Game-Controller durchnummerieren – kostenlos für Windows.**

🌐 Website: https://khoron-ip.github.io/numora/
⬇️ Download: [Numora-Setup-1.3.0.exe](https://github.com/khoron-ip/numora/releases/download/v1.3.0/Numora-Setup-1.3.0.exe)

Numora bringt viele Fotos schnell in die gewünschte Reihenfolge und exportiert sie als 001.jpg, 002.jpg …
– mit Großansicht, Auswahl-Fenster, frei belegbarer Tastatur-/Controller-Steuerung und 17 Designs
(darunter zwei für Konzertfotografie). Läuft komplett offline, die Originale bleiben unverändert.

Dieses Repository enthält die Website (GitHub Pages). Der Installer liegt unter
[Releases](https://github.com/khoron-ip/numora/releases).
